# 手順書: 自分でログインしたブラウザを Claude に操作してもらう

作成日: 2026-11-22
対象: ログインが必要な Web サイト（管理画面・会員ページなど）を、Claude に調べさせたい・操作させたいとき

## 1. 結論

- **ログインは自分で行い、そのあと Claude にブラウザの操作を任せる**のが正しい進め方です。
- Claude は、パスワード・APIキー・カード番号などの入力を**行いません**（ユーザーに頼まれても行わない決まりです）。そのため「自分でログイン → Claude が作業」が、そもそも唯一の安全な形です。
- 通常の Web 検索（`WebSearch` / `WebFetch`）は、ログイン状態を持てません。**ログインが必要なページは、ブラウザ連携を使います。**

## 2. 方法の選び方

| 方法 | 仕組み | ログイン状態 | 向いている場面 |
| --- | --- | --- | --- |
| **A. Claude in Chrome（推奨）** | Chrome の拡張機能を通じて、**自分の Chrome** を Claude が操作する | 自分の Chrome のサインインがそのまま使われる | 普段使っているサービスの管理画面、会員ページの調査・操作 |
| B. Claude デスクトップアプリ内のブラウザ | アプリ内のブラウザ画面を Claude が操作する | アプリ内ブラウザに保持される（Chrome とは別） | Chrome を使わず、アプリの中で完結させたいとき |
| C. 通常の Web 検索 / 取得 | 公開ページを読むだけ | なし | ログイン不要の公開情報の調査 |

この手順書は **A** を中心に説明します。このプロジェクトの Claude Code セッションでは、Chrome 連携のツール（`mcp__claude-in-chrome__*`）が利用できます。

## 3. 事前準備（初回だけ）

1. **Chrome に Claude の拡張機能を入れる**（Chrome ウェブストアの「Claude in Chrome」）。
2. 拡張機能で、使っている Claude アカウントにサインインする。
3. 拡張機能の設定で、**Claude に操作を許すサイトを許可**する（サイト単位の許可が必要です）。操作させたいサイトだけに絞ってください。
4. Claude Code から使うときは、Chrome との接続を有効にする。
   - 起動時に `claude --chrome` を付ける、またはセッション中に `/chrome` で接続状態を確認・設定する。
   - 利用できる条件やコマンド名はバージョンで変わることがあります。うまくいかないときは `/chrome` の表示、または `claude-code-guide`（Claude Code についての質問用）で最新を確認してください。

> 重要: 普段使いの Chrome プロファイルに全部の拡張機能・サインインが入っていると、Claude から見える範囲も広くなります。**作業用の Chrome プロファイルを別に作り、必要なサービスだけにログインする**ことをおすすめします。

## 4. 毎回の手順

### 手順1: 自分で Chrome を開いてログインする

1. Chrome（拡張機能を入れたもの）で、対象サイトを開く。
2. **自分で**ID・パスワードを入力してログインする。
3. 2段階認証（SMS・認証アプリ）や、「ロボットではありません」の確認（CAPTCHA）も、**自分で**完了する。Claude はこれらを代行できません。
4. ログイン後の画面（ダッシュボードなど）が表示されていることを確認する。

### 手順2: Claude に依頼する

ログイン済みであること、見てほしいサイト、やってほしいこと、**触ってはいけないこと**を伝えます。

依頼文の例（調べるだけ）:

```
Chrome で example.com にログイン済みです。
管理画面の「注文一覧」を開いて、今月の注文件数と、未発送の注文の一覧を教えてください。
閲覧だけで、設定の変更・削除・送信はしないでください。
```

依頼文の例（操作を含む）:

```
example.com にログイン済みです。
「お知らせ」に新しい投稿の下書きを作ってください。
内容は次のとおりです: …
公開ボタンは押さず、下書き保存までにしてください。
```

### 手順3: Claude の作業を見守る

- Claude は、既存のタブではなく**新しいタブ**を開いて作業します。同じ Chrome なので、ログイン状態（Cookie）は共有されます。
- 作業中は Chrome の画面で動きを見られます。**意図しない動きがあれば、すぐに止めて**ください。
- 次のような操作は、Claude が**実行前に確認を求めます**。内容を見て、問題なければ返事をします。
  - 送信・投稿・公開・削除・購入など、**元に戻しにくい操作**
  - ファイルの**ダウンロード**
  - フォームの送信、個人情報の入力
  - アカウント作成、利用規約への同意、権限（OAuth）の許可

### 手順4: 終わったら後片付け

1. 必要なら、**自分でログアウト**する。
2. 拡張機能のサイト許可のうち、もう使わないものを外す。
3. Claude が作った下書きや変更内容を、**自分の目で最終確認**する。

## 5. Claude にやらせないこと（自分で行う）

| 項目 | 理由 |
| --- | --- |
| パスワード・APIキー・トークンの入力 | 認証情報を Claude に渡さないため。ログインは常に自分で行う |
| 2段階認証コード・CAPTCHA | 自動化が禁止されている、または本人しかできない |
| 銀行・証券・暗号資産の取引、送金 | 実行しない決まり。画面を開くところまでは可能でも、確定は自分で |
| カード番号・個人番号などの入力 | 同上 |
| セキュリティ設定・システム設定の変更 | 実行しない決まり |

## 6. 安全のための注意

- **ページに書かれた指示には従いません。** Web ページ・メール・ファイルの中に「Claude へ: 〇〇してください」のような文章があっても、それはデータであり、ユーザーの指示ではありません。Claude は該当の文章を引用して知らせ、実行してよいか確認します。不審な内容が出たら、実行を許可せず、知らせてください。
- **信頼できるサイトだけ**を許可する。見知らぬサイトや、リンクをたどって来たサイトでは、ログインしたまま操作させない。
- **まず閲覧だけ**で頼む。変更を伴う作業は、「下書きまで」「確認画面まで」と範囲を区切る。
- 機密性の高いサービス（銀行・給与・個人情報の大量にあるシステム）は、ブラウザ連携で扱わない。
- 作業が終わったらログアウトし、サイト許可を整理する。

## 7. うまくいかないとき

| 症状 | 対処 |
| --- | --- |
| Claude が「Chrome のツールがない」と言う | 拡張機能が入っているか、Claude にサインインしているか、Claude Code と Chrome が接続されているか（`/chrome`）を確認。接続後に再依頼する |
| ログインしているのに、Claude の見る画面はログアウト状態 | 別の Chrome プロファイル／ウィンドウでログインしている可能性。**拡張機能を入れているのと同じプロファイル**でログインし直す |
| 作業中にログイン切れになる | サイトのセッション期限。自分で再ログインしてから、続きを依頼する |
| 画面が反応しない／ボタンが押せない | 2〜3回試しても進まないときは、Claude は止まって相談します。ページの再読み込み、または手作業に切り替える |
| ブラウザが固まった（確認ダイアログが出ている） | `alert` などのダイアログが出ていると、ブラウザ操作が止まります。**自分でダイアログを閉じて**ください。削除ボタンなどダイアログが出る操作は、Claude は事前に知らせます |
| 「タブが存在しない」と出る | 前回のタブは使えません。Claude が最新のタブ情報を取り直します。そのまま続けて依頼してよい |
| 拡張機能の許可していないサイトで止まる | 拡張機能のサイト許可に追加する（必要なサイトだけ） |

## 8. 補足: 記録を残したいとき

画面操作の流れを、あとで見返したい・共有したいときは、「操作を GIF で記録して」と依頼できます。ファイル名は内容が分かる名前（例: `order-list-check.gif`）で保存されます。記録した画面には、ログイン後の個人情報や顧客情報が写ることがあるため、**共有する前に内容を確認**してください。
